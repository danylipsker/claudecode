# Curves Workshop

Every figure of Robert C. Yates, *A Handbook on Curves and Their Properties* (J. W.
Edwards, Ann Arbor, 1947), redrawn from its geometry as a construction you can play step
by step and then draw yourself — with a straightedge, a compass, dividers and a pencil —
on the practice board of the app or on paper.

Open `index.html` (served: `node ../scripts/serve.js 8172` from the repository root and
http://localhost:8172/CURVES-BOOK/). No build step, no libraries, no network.

## What is here

| | |
|---|---|
| `index.html`, `js/app.js`, `css/app.css` | the app: home, the 45 sections of the book, every figure with its step player, the gallery, the tools page, search |
| `js/board.js` | the practice board: point, straightedge, compass, dividers, set square and pencil tools, snapping to intersections, every stroke checked against the construction |
| `js/kit.js` | the drawing kit — geometry helpers, the book's curves as parametric functions, the step/tool model, the SVG renderer |
| `figures/<section>.js` | the figures of the book, one file per section, each figure a `Curves.figure({...})` with its construction in steps |
| `data/sections/<id>.js` | the text of each section: history, description, equations, properties, general items, tables, bibliography |
| `data/manifest.js` | the sections and figure numbers of the book with their pages |
| `svg/*.svg` | **the drawings as files**: 329 of them, one per figure or panel (`fig-009.svg`, `fig-048a.svg`) for all 211 figures of the book, generated by `tools/build-svg.js` |
| `docs/` | the documentation: one Markdown page per section with every figure, its steps, equations and properties ([index](docs/README.md), [every figure](docs/FIGURES.md), [the tools](docs/TOOLS.md)) |
| `AUTHORING.md` | how a figure and a section are written |
| `gallery.html` | review page: a figure beside the scanned page (needs `scan/`, local only) |

## The idea

The book is a reference: for each curve its history, how it is generated, its
equations, its metrical properties, its general items, and a figure. Here each figure is
rebuilt as a sequence of steps, each made with one named tool — *given*, *straightedge*,
*compass*, *dividers*, *set square*, *pencil* … — so that a learner can:

1. **play** the construction and see each stroke appear in order (the figure page);
2. **repeat** it on the practice board, where the board snaps to intersections and
   checks every stroke against the construction, with hints when stuck;
3. **print** the worksheet and do it on paper with real tools.

The drawings follow the book's figures element by element (the same letters, hatching,
arrows and angle marks), but every point is computed, every curve comes from its
equation, and every construction is geometrically true.

## Tools

```
node tools/validate.js            # checks every figure and section against the manifest
node tools/build-svg.js           # writes svg/<id>.svg for every figure
node tools/catalog.js             # rebuilds data/catalog.js (the index the page loads)
node tools/docs.js                # rebuilds docs/
python tools/scan-crop.py 10 0.5 0.9   # a close-up of a scanned page (authoring; needs scan/)
```

Browser self-test, from the console of `index.html`:

```js
await new Promise(ok => { const s = document.createElement('script'); s.src = 'tools/selftest-browser.js?' + Date.now(); s.onload = ok; document.head.appendChild(s); });
CurvesSelfTest({});                    // every figure: the page renders, the steps play, the board completes
JSON.stringify(window.__selftest)      // poll
```

## Source

The scanned book (`*.pdf`) and the page images (`scan/`) stay out of the repository;
they are only used to author and check the drawings. The prose of the app is written
for it; the formulas, names, dates and bibliography are the book's.
