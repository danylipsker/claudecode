# Curves Workshop — authoring guide

How the figures of Robert C. Yates, *A Handbook on Curves and Their Properties* (1947)
are rebuilt as construction drawings, and how a section of the book becomes a page of
the app. Read this whole file, then read `figures/_reference.js` (Fig. 1a, 1b and 9) and
`data/sections/astroid.js`: they are the reference for style, depth and tone.

Plain JavaScript, no build step, no libraries, no network at run time. Everything must
work offline from the files in `CURVES-BOOK/`.

## What a figure is for

The app teaches how to draw curves the classical way: with a straightedge, a compass,
dividers, a pencil, and the drafting helpers of 1947 (set square, ruler, protractor,
French curve). Every drawing in the book is rebuilt as a **sequence of steps, each made
with one tool**, so the learner can play it step by step, then repeat it on the practice
board or on paper. The final SVG must look like the book's figure: the same elements,
the same labels, the same hatching, arrows and angle marks, drawn cleanly.

Not every figure in the book is a construction (some are graphs, tables of curves,
linkages, a photograph of a nautilus). Those are still drawn — as a `given` step plus
`note`/`pencil` steps — so the book is complete; the construction steps are for the
figures that show how to make something.

## Files

```
CURVES-BOOK/
  js/kit.js               the drawing kit and the SVG renderer (do not edit — report problems)
  data/manifest.js        the sections and the figure numbers of the book, with pages (do not edit)
  figures/<section>.js    the figures of one section, e.g. figures/cardioid.js     ← you write these
  figures/_reference.js   Fig. 1a, 1b, 9 — the reference (do not edit, do not redefine its ids)
  data/sections/<id>.js   the text of one section of the book                      ← you write these
  scan/pNNN.jpg           the scanned pages, NNN = the page number printed in the book (local only)
  scan/crops/             your close-ups (tools/scan-crop.py)
  svg/<id>.svg            GENERATED by tools/build-svg.js
  tools/build-svg.js      draws the SVG files
  tools/validate.js       checks figures and sections against the manifest
  tools/scan-crop.py      cuts a piece of a page at readable size
  gallery.html            your drawing next to the page of the book, for checking
```

Write only the files you were given. Do not edit `kit.js`, the manifest, the reference
file, or another writer's files.

## Checks you must run

```
node --check figures/<section>.js
node tools/build-svg.js <section>            # draws svg/<id>.svg for that file, reports failures
node tools/validate.js <section>             # 0 errors required; read the warnings
```

Then look at every figure next to the book page. The static server runs at
`http://localhost:8174/CURVES-BOOK/gallery.html?section=<section>` (or
`?figs=fig-012,fig-013a`). If you use the browser, open **your own tab** (`tabs_create`,
then `navigate` with that `tabId`, and pass the `tabId` to every call) — other writers
share the browser. Take a screenshot and compare with the scan beside it. Fix, rebuild,
reload.

To read a figure closely, cut it out of the page at full resolution:

```
python tools/scan-crop.py 10 0.55 0.95            # page 10, 55%–95% of the height
python tools/scan-crop.py 10 0.55 0.95 0.1 0.8    # and 10%–80% of the width
```

and open the printed path with the Read tool. **Always look at the full-resolution crop
of a figure before drawing it**; the small page image loses the labels and the thin lines.

## A figure file

```js
/* Curves Workshop · figures/cardioid.js — Figs. 3–5 (pages 4–7) */
Curves.figure({
  id: 'fig-003a',             // fig-NNN (one drawing) or fig-NNNa, fig-NNNb … (the panels of one figure)
  section: 'cardioid',        // the section id from data/manifest.js
  page: 4,                    // the page the figure is printed on
  title: 'The cardioid as an epicycloid of one cusp',   // what the drawing shows, in a few words
  tags: ['roulette', 'epicycloid'],                      // optional
  note: 'The book draws the rolling circle at t = 60°.', // optional: anything a reader should know
  build(k) {
    const a = 80;
    const O = k.pt(0, 0);
    k.given('The fixed circle of radius a with centre O, and the axes.', () => {
      k.axes(O, { x: [-a * 1.3, a * 3.4], y: [-a * 2.2, a * 2.4] });
      k.circle(O, a, { hatch: 'in' });
      k.point(O, 'O', 'sw');
    });
    k.step('compass', 'The rolling circle, equal to the fixed one, touching it at T.', () => { ... });
    k.step('pencil', 'The cardioid, the path of P.', () => {
      k.curve(k.curves.cardioid(a), [0, k.TAU]);
    });
  }
});
```

Panels: when the book prints one figure as two or more drawings labelled (a), (b) …,
make one `Curves.figure` per panel: `fig-003a`, `fig-003b`. When it is a single drawing,
`fig-003`. The letters follow the book; a figure with several unlabelled drawings in a
row gets letters from left to right, top to bottom. The manifest says how many panels
were seen on each page; the page decides.

### Steps and tools

Every shape is drawn inside a step. The first step is normally `given`. Choose the tool
honestly — it is what the learner will be told to pick up:

| tool | use it for |
|---|---|
| `given` | the data: fixed circles, axes, foci, a given curve, the constant lengths |
| `straightedge` | a line through two known points, a tangent through two known points |
| `compass` | a circle or an arc about a known centre with a radius taken from the drawing |
| `dividers` | carrying a length, stepping off equal parts along a line or a circle |
| `ruler` | laying off a stated length (drafting) |
| `square` | a perpendicular or a parallel through a point (drafting) |
| `protractor` | laying off a stated angle (drafting) |
| `pencil` | drawing the curve through the points found (French curve) — the result |
| `roll` | the rolling motion of a generating circle: one or more positions drawn |
| `fold` | a crease of the paper (envelopes by folding) |
| `linkage` | bars and pivots of a mechanism |
| `note` | an explanation drawn on the figure: angle marks, arrows, hatched areas, extra labels |

Step texts are instructions to the person drawing, one or two sentences, saying *what*
and *why*: "With the radius F1Y, draw the circle about F2. It cuts the first circle at P:
F1P · F2P = k², so P is on the curve." Use the book's own letters. Write `F1`, `P'`, `π − t`
in step texts as plain text (no TeX there).

The `pencil` step with the finished curve comes last (or after each piece). When the
book's figure shows a curve that is *given* (a pedal of a given curve, a caustic of a
given circle), the given curve goes in the `given` step and the derived curve in the
`pencil` step. A figure that is only a graph (Sketching, Functions with discontinuous
properties, Trigonometric functions) is `given` (axes) + `pencil` (the graph) + `note`
(labels, asymptotes dashed).

### The kit (`k`)

Coordinates are mathematical: y upwards; pick units so the figure spans about 200–500
units (the reference uses a = 150 for a circle that fills the figure). Everything is
scaled to the final frame, so only proportions matter.

Points are `{x, y}` objects. `k.pt(x, y)` makes one without drawing it.

| call | draws |
|---|---|
| `k.point(P, 'P', 'ne')` | a dot and its label, the label at the compass direction n ne e se s sw w nw (default ne); options as a third object: `{at:'ne', open:true, r:0.8, dist:1.3}` |
| `k.P(x, y, 'P', 'ne')` | makes the point and draws it (returns it) |
| `k.dot(P, {open:true})` | a dot without a label (`open` = white with a rim, as the book draws points) |
| `k.label(P, 'text', 'ne', {dist:1.5, size:0.9, upright:true})` | a label beside a point. `P_1`, `P_{12}`, `T'`, `x^2`, `ar{A}` give subscripts, superscripts and an overbar; Greek letters typed as they are: θ φ π ρ |
| `k.text(x, y, 'text', {anchor:'middle', size:1, upright:true, rotate:30})` | text at a place (for equations under a drawing, names of curves); `rotate` in degrees, counter-clockwise, to write along a line |
| `k.seg(A, B, o)` | a segment |
| `k.line(A, B, o)` | the whole line through A and B, cut by the frame (use for asymptotes, directrices, the long lines of the book) |
| `k.ray(A, B, o)` | from A through B to the frame |
| `k.arrow(A, B)` | a segment with an arrow head at B (velocities, directions) |
| `k.poly([A, B, C], {close:true})` | a polyline / polygon |
| `k.circle(C, r, o)` | a circle. `o.hatch:'out'` or `'in'` draws the short strokes the book uses for a fixed circle; `o.arrow: angle` puts a direction arrow on it (`cw:true` for the other sense); `o.label:'a'` writes a name beside it |
| `k.arc(C, r, a0, a1, o)` | the arc about C from angle a0 to a1 counter-clockwise (radians); `o.arrow:true` puts a head at the end; `o.cw:true` draws from a0 to a1 *clockwise* (so an arc that goes the long way round with `cw` wants its angles swapped) |
| `k.arc3(C, P, Q, o)` | the arc about C from the point P to the point Q, counter-clockwise |
| `k.curve(f, [t0, t1], {n:400, arrow:t})` | a parametric curve, `f = t => [x, y]` (return `null` where undefined); `arrow` puts a direction head at the parameter t (or a list). Also accepts an array of points |
| `k.fn(f, [x0, x1])` | the graph y = f(x) |
| `k.polar(f, [θ0, θ1])` | r = f(θ) |
| `k.ellipse(C, a, b)` | an ellipse with its axes along x and y |
| `k.smooth([A, B, C, …], o)` | a smooth curve through control points (for the book's freehand *given* curves) |
| `k.poly(pts, {close:true, fill:'#fff'})` | an opaque body (a filled polygon hides what is behind it: carpenter's squares, bars) |
| `k.angle(V, A, B, {label:'t', r:1, n:2, arrow:true})` | an angle mark at V from VA to VB counter-clockwise, `n` concentric arcs |
| `k.right(V, A, B)` | a right-angle mark |
| `k.dim(A, B, 'a', {side:'right', dist:1})` | a length written beside AB |
| `k.hatch([A, B, C], {angle:π/4, gap:1, fill:'#ddd', outline:true})` | a hatched area (the book shades areas and sectors this way) |
| `k.head(P, dir)` | an arrow head at P pointing along the vector dir |
| `k.tick(P, dir)` | a short tick across the direction dir (equal-length marks) |
| `k.pivot(P, {size:1.5})` / `k.bar(A, B, {w:1.5})` | a linkage pivot (double circle) and a bar (a thick hollow line); `size` and `w` scale them |
| `k.axes(O, {x:[-120, 160], y:[-100, 140], xl:'X', yl:'Y', arrows:true})` | the axes with arrow heads and labels, as the book draws them |

Options common to lines, circles, arcs, curves: `cls` — `'given'` (black, the normal
weight), `'cons'` (construction lines: thinner, grey), `'aux'` (lighter still), `'curve'`
(the result: heavier, blue; the default for `k.curve`), `'thick'` (a heavy black line, as
the book's emphasised bars); `dash:true`, `dotted:true`; `width:` an explicit stroke
width; `stroke:` an explicit colour; `nobounds:true` to keep a shape from stretching the
frame.

Frame: the drawing area is the box around everything drawn, with a margin. Use
`k.frame(x0, y0, x1, y1)` to fix it yourself (e.g. to cut a curve that runs to infinity
or to leave room for a label), and `k.pad(0.1)` to change the margin.

### Geometry helpers (`k.g`) — use them, do not re-derive

`add sub mul dot cross len dist unit perp rot(v, θ) rotAbout(P, C, θ) mid lerp(A, B, t)
polar(C, r, θ) along(A, B, d) angleOf(v) angle(A, V, B) dir(θ) deg(d) rad(r)
lineLine(A, B, C, D) segSeg lineCircle(A, B, C, r) circleCircle(C1, r1, C2, r2)
foot(P, A, B) reflect(P, A, B) tangentPoints(P, C, r) circumcenter incenter centroid
parallelThrough(P, A, B) perpThrough(P, A, B) inversion(P, C, k²) frenet(f, t)
curvature(f, t) centerOfCurvature(f, t) arcLength(f, t0, t1)`

Everything a construction needs — a foot of a perpendicular, where a circle meets a
line, the centre of curvature — is there, so your points are *computed*, never guessed.
The construction must be geometrically true: if the book says "CY perpendicular to CX",
the point Y is the foot you compute, and the right-angle mark is at C.

### The curves (`k.curves`)

Parametric functions, `t => [x, y]`, with the book's parameters:

`circle(r) ellipse(a,b) hyperbola(a,b) parabola(p) astroid(a) cardioid(a) nephroid(a)
deltoid(a) epicycloid(a,b) hypocycloid(a,b) epitrochoid(a,b,h) hypotrochoid(a,b,h)
cycloid(a) trochoid(a,h) limacon(a,k) lemniscate(a) lemniscateParam(a) cissoid(a)
conchoid(a,k,±1) strophoid(a) witch(a) folium(a) catenary(a) tractrix(a) semicubic(a)
cubicParabola(A,B,C,D) sine(A,w) equiangularSpiral(a,k) archimedes(a) hyperbolicSpiral(a)
lituus(a) fermat(a) sinusoidal(a,n) rose(a,k) cassini(a,k,±1) involuteOfCircle(a)
kieroid(a,b) euler(a) pursuit(k) normal(σ) exp(a,k)`

Read their definitions in `js/kit.js` (orientation, where the cusp is) before using one,
and shift or rotate the points yourself when the book places the curve differently:
`k.curve(t => { const [x, y] = f(t); return [x + 40, -y]; }, [0, k.TAU])`. Curves not in
the list are written in place as a function.

### Drawing like the book

* The book's fixed circles carry short hatch strokes on the far side (`hatch:'out'` or
  `'in'`); its points are small open circles (`k.dot(P, {open:true})` or
  `k.point(P, 'P', {open:true})`); its construction lines are thin, its results heavy.
  Directions of motion are arrow heads on the curve or circle.
* Label every point the book labels, with the same letter, placed where the book places
  it. Use `dist` to push a label away from a crowded spot.
* The axes are labelled X and Y at their arrow heads, as in the book, and O at the origin.
* Equations that the book prints under a figure (x = a cos t …) are written with
  `k.text(x, y, 'x = a cos t', {upright:true, size:0.9, anchor:'start'})` below the drawing.
* Where the book's drawing is only approximate (a freehand sketch of a curve), draw the
  true curve from its equation. Where the book's drawing has a mistake, draw it right and
  say so in `note`.
* A length that the construction needs but does not construct (the constant k of a
  Cassinian, the radius a, the distance of a conchoid) is **given**: draw it in the
  `given` step as a short segment with ticks and its name, somewhere free (see Fig. 9 in
  the reference), so the learner can take it with the dividers. A point laid off at a
  given length is then a `dividers` step.
* A rolling circle is drawn at one position (the book's), with the tracing point, the
  contact point and the line of centres; the `pencil` step draws the whole curve.
* Never fit a curve by eye: every curve comes from an equation or from the geometry.

### Practice targets

The practice board asks the learner to reproduce the shapes drawn in the
`straightedge`, `compass`, `dividers`, `ruler`, `square`, `protractor` and `pencil` steps
(points, lines, circles, arcs, curves), in order. Shapes with `cls:'aux'` are not
checked. So: put the real construction in those steps, and the decorations (angle marks,
hatching, direction arrows) in `note` steps or with `cls:'aux'`.

## A section file

`data/sections/<id>.js` gives the app the text of the section: a short history, the
description, the equations, the metrical properties, the general items, the
constructions to practise, the bibliography. See `data/sections/astroid.js`.

```js
Curves.section({
  id: 'cardioid',                     // from the manifest
  title: 'Cardioid',
  pages: [4, 7],
  history: '…',                        // 1–3 sentences, in your own words
  description: '…',                    // markdown with $TeX$; say what the curve is and how it is generated
  equations: [{ tex: '…', note: 'rectangular' }, …],
  metrical: [{ tex: 'L = 16a', note: 'length' }, …],
  items: [{ label: 'a', text: '…' }, …],          // the "general items", each in a sentence or two
  constructions: [{ fig: 'fig-003a', title: '…', level: 1 }, …],   // the figures a learner can practise, easiest first; level 1–3
  tables: [{ title: '…', head: ['Curve', 'Pedal point', 'Pedal'], rows: [['…', '…', '…']], note: '…' }],   // the book's tables, when the section has them (note: a footnote)
  extra: 'markdown shown after the tables — longer discussions the items cannot hold (a linkage, a derivation)',
  bibliography: ['Edwards, J.: Calculus, Macmillan (1892) 337.', …],
  seeAlso: ['epi-hypo-cycloids', 'evolutes']       // other section ids
});
```

Text is markdown with `$inline TeX$` and `$$display TeX$$` (fractions, roots, Greek,
sub/superscripts, `\tfrac`, `\sqrt`, `\cos`, `\theta` …). `[[section-id]]` links to a
section, `[[fig-009]]` to a figure. **All prose must be your own words**: read the page,
understand it, and explain it as you would to a student — do not copy the book's
sentences. Formulas, constants, names, dates and the bibliography entries are facts and
are kept exactly. Keep the book's lettering (a, b, k, t, θ, φ, p, R, s) in the formulas.
Every equation and metrical property printed in the section goes in; every general item
goes in (shortened to its point); the book's tables go in as tables.

## Quality bar

A figure is done when: it builds and validates with 0 errors; side by side with the scan
it shows the same elements, letters and emphasis; each step is a true instruction with
the right tool; the curve is exact; the labels do not sit on lines. A section is done
when a student could learn the section from it without the book.
