## Decisions

- **The clipper is edge-splitting + midpoint classification, not the Martinez-Rueda sweepline the
  plan specified.** This is a real deviation and worth understanding. The plan chose Martinez
  specifically because Greiner-Hormann breaks on shared and collinear edges, which grid snap makes
  the common case here. That requirement is met a different way: every edge of both operands is cut
  at all crossings, each piece is classified by its midpoint, and a piece lying *on* the other
  polygon's boundary is decided by comparing the two edge directions — an explicit four-case rule —
  rather than by an inside/outside test, which is a coin flip exactly there. Same O(n²) cost the plan
  already accepted at this scale, far less code, and correctness that can be reasoned about locally.
  The judgement was that a correct splitter beats a probably-correct sweepline inside one session.
  Martinez remains open if exact sweep semantics are ever wanted.
- **Boolean tolerance follows geometry size, not zoom.** The plan said "~0.05px at current zoom".
  That makes permanent geometry depend on transient view state — union while zoomed out and you keep
  a coarser result forever. Now `clamp(span * 0.0005, 0.02, 1.5)` off the operands' bounding box.
  Verified identical output at 5% and 300% zoom.
- **Exact path preserved.** When no input segment was ever sampled (`hadCurves === false`) the result
  is emitted straight to `seg:'line'` nodes after dropping collinear runs. Two snapped rectangles
  union to integer coordinates with zero approximation. Curved input is sampled and refitted to
  cubics, so a booleaned arc loses its bulge and exports to DXF as a polyline. Known, accepted.
- **Difference keeps the bottom-most shape and its style**, matching Inkscape "Minus Front", as
  planned. Operands remember which selected shape they came from, so a text operand that explodes
  into several glyphs is still treated as one subject.
- **`e6f770e` was not amended.** It was already on `origin/main` by the time the mismatch was
  noticed; rewriting pushed history to improve a commit message is not worth the cost.
