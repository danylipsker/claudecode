## Decisions

- **One mixed commit rather than splitting docs from the July factor work.** The factor
  feature and the new comments are interleaved in the same three files, so a clean split
  needed hunk surgery; the commit body carries the breakdown instead.
- **Comments state quirks honestly instead of fixing them silently** — the user asked for
  documentation, not behavior changes. Known issues are now marked in place (DPI-dependent
  elbow-collision margin, silent out-of-reach IK clamp, vertical-elbow NaN case, inert
  `IsSpecial`/`cuttingDistance`, `_zeroY` valid only after first draw, rotation animation
  timing) and collected in ARCHITECTURE.md §8.
- **Insertions were made by a Python annotator with exact-unique-anchor verification**, BOM
  and CRLF preserved byte-for-byte per file (`scratchpad/annotate_lib.py` + 4 batch scripts;
  scratchpad only, not committed). Bash heredocs proved unreliable for content with
  backslashes in this harness — scripts went through the Write tool instead.
- **Mermaid over images** for the diagrams so GitHub renders them for Aviv; labels use
  `<br/>` (mermaid doesn't honor `\n` in flowchart labels).
- **Auto-generated files skipped on purpose**: `Properties/*.Designer.cs`, `AssemblyInfo`,
  `obj/`.
- **Fixed the inner repo's remote in passing**: `.git/config` held the literal placeholder
  `https://github.com/[USERNAME]/[REPOSITORY].git`. Restored from the URL recorded in git's
  own merge history. SSH was denied (`publickey`) even though the outer repo uses SSH, so it
  is set to **HTTPS + Git Credential Manager**, which authenticated with cached credentials.
