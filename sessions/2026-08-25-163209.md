## Summary
Added a new self-contained project, "Affine Transformations Lab" — a single-page HTML/JS/canvas tool for building, composing, and visualizing 2D/3D affine transformation matrices, plus a separate quaternion stack for 3D rotation composition and slerp interpolation.

## What changed
- New tool: [afine-transformations.html](afine transformations/afine-transformations.html) — dark-themed UI with a left control panel and a canvas viewport.
  - Editable matrix stack (2D or 3D, switchable dimension) where each matrix's cells accept arbitrary expressions (custom tokenizer/parser supporting `+ - * / ^`, unary minus, parens), not just literal numbers.
  - Matrices in the stack compose by multiplication into a single result matrix, with determinant shown and a live canvas render of the composed transform applied to a test shape (an asymmetric "F" polygon, chosen so orientation/chirality flips are visible).
  - Preset insertion (rotation, scale, shear, translation, etc.) into whichever matrix is selected, matrix reordering (`move`), enable/disable per matrix, ghost overlay of the untransformed shape, and basis-vector display toggle.
  - Animation of the composite transform from identity, driven by a render loop (`update`/`loop`/`resize`).
  - Separate quaternion stack (add/reorder/enable quaternions) for 3D rotation, with conversions between quaternion, 3x3/4x4 matrix, axis-angle, and Euler (ZYX) representations (`qToMat3`, `mat3ToQ` via Shepperd's method, `qToAxisAngle`, `axisAngleToQ`, `eulerToQ`, `qToEuler`), composed quaternion multiplication, and a slerp control (button + range slider) to interpolate identity → composed quaternion.
  - A cheatsheet panel explaining how each transform type is represented mathematically.

## Decisions
- Matrix cell inputs accept expressions rather than plain numbers (custom recursive-descent parser: `tokenize`/`parseExpr`/`term`/`unary`/`pow`/`primary`), so users can type things like `cos(30)` or reference angles symbolically instead of pre-computing decimals.
- Kept the tool as a single dependency-free HTML file (no build step, no external libraries) consistent with the other small interactive tools already in this repo (sokoban, circuits, etc.).
