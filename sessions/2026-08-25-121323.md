## Summary

First recorded SOKOBAN session. The game ([sokoban.html](../sokoban.html)) previously played only
its 16 hardcoded levels; it can now open external level files at runtime. A new **Open** button
(shortcut `O`) reads a `.txt` file and shows a modal browser with a canvas-drawn miniature of
every level in the file — click one to play it. Built for the DeepMind boxoban dataset the user
downloaded this morning (`boxoban-levels-master/hard/*.txt`, ~1000 levels per file), but the
parser also accepts the generic `Level N` format, so `niveles.txt` (the 155-level Microban set,
committed alongside) opens too.

## What changed

- Level-pack loader: `<input type="file">` + FileReader + `parseLevelPack()`, which treats a line
  as board data when it holds only Sokoban glyphs and at least one `#`; other lines separate
  levels and may name them (`; 0` boxoban headers or `Level N` headers) (sokoban.html)
- Pack browser modal: thumbnail grid rendered straight from the level text onto small canvases,
  drawn lazily via IntersectionObserver because packs run to 1000 levels (~0.4 s to open) (sokoban.html)
- Pack plumbing: active pack overrides `LEVELS`; progress keys are namespaced `pk:<file>:<i>` so
  classic bests survive; par is optional (HUD shows "—", the par medal is skipped, best-moves
  tracking takes over); **Levels** reopens the pack browser while a pack is active; **Classic
  Levels** returns to the built-in set at the remembered index (sokoban.html)
- Unwinnable grids (no player, no crates, or more crates than goals) are silently dropped at
  parse time instead of crashing the engine (sokoban.html)
- `sokoban/boxoban-levels-master/` gitignored — 171 MB of re-downloadable third-party data
  (.gitignore)
- `niveles.txt` added: Microban 155-level set in the generic text format (sokoban/niveles.txt)

## Decisions

- **File picker over fetch()** — the game runs from `file://`, where `fetch` of local files is
  blocked; `<input type="file">` + FileReader works everywhere and needs no server.
- **Pack progress namespaced by filename** (`pk:000.txt:12`), not merged into the `lv<i>` keys,
  so external packs can never corrupt classic-level bests. Tradeoff accepted: renaming a pack
  file orphans its recorded progress.
- **On opening a file the pack's first level loads immediately.** Deferring activation until a
  thumbnail click left a window where `pack` pointed at the new file while the board still ran a
  classic level, so a win would have recorded under the wrong key.
- **Levels with more crates than goals are dropped, not warned about** — the engine's win check
  (`every box on goal`) can never pass for them. Crates ≤ goals is allowed.
- **Thumbnails draw from the raw text rows, not `parseLevel()` output** — no reachability pass,
  whole canvas floor-filled first. Correct silhouettes matter on the real board, not at 92 px.
- **Boxoban dataset stays out of git** — third-party, 171 MB, Apache-licensed, re-downloadable
  from https://github.com/deepmind/boxoban-levels. The game reads it at runtime instead.
