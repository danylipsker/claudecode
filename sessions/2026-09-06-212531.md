# Session — 2026-09-06 21:25

**Branch:** main · **Commit:** `85153f8`

## Summary

A long feature session on VectorLab (`VECTOR-EDITOR/vector-editor.html`) that took the editor from
"draw and transform shapes" to something closer to a real illustration tool: align/distribute with
profiles and guide curves, morphing, document setup with real paper sizes and units, rulers with a
movable origin, guide lines, a full snapping engine, a raster tracer with an auto-recommender, a
dockable/floating/parkable panel system driven by right-click menus, and complete vertex/edge
context menus. The last third of the session was spent making the tracer actually good — it now
reproduces test geometry to within ~0.5 px with the minimum vertex count. Everything was verified
in the in-app browser against known geometry; nothing was committed until now, so this is one
large commit.

## What changed

- **Align & distribute panel**: align to selection / last selected / first selected / page / page
  margin / whole drawing, with Ctrl/Alt/Shift modifiers overriding the reference per click
  (Shift = place outside with a gap). Distribute by centres / gaps / start / end edges, in position,
  selection or stacking order, fit-to-reference or fixed step, with spacing profiles (linear, ease
  in/out/in-out, crowd middle, sine, log, exp, geometric ratio, random) and a live dot preview.
- **Guide curves**: add an arc / S-wave / ellipse / line across the selection and place shapes along
  any path by arc length, optionally rotated to the tangent. Closed guides spread without doubling
  the start. "Onto line" moves one shape's centre to the nearest point on a line, or spreads several.
- **Morphing**: in-between shapes from the first selected to the second (cubic segment matching,
  rotation/reversal to the closest correspondence, style interpolation), a third open path as spine,
  the distribute profile spacing the steps; result is a group, "Break apart" ungroups it.
- **Ghost previews**: hovering any align/distribute/morph/guide button dry-runs the action with
  undo/save/status muted and draws the would-be positions as dashed ghosts; live under held
  modifiers and while adjusting the section's controls.
- **Document**: paper presets (A0–A6, B4, B5, Letter, Legal, Tabloid, Executive, HD/FHD/4K/Square),
  orientation, units (px/mm/cm/in/pt) applied to rulers, status bar, Transform fields, grid and
  guide positions. Rulers with 1-2-5 ticks, origin at any corner / centre / dragged anywhere
  (snapping), "Y axis up". Grid anchored on the origin with a major-line count.
- **Guides and snapping**: drag guides out of rulers, back to remove, editable list. Snap engine for
  vertices, midpoints, edges, shape/arc/ellipse centres, box corners, page edges/centre/origin,
  guides and crossings, grid; used by drawing, moving (nine box points), node/handle drags, guide
  and origin placement; orange marker names the snap. Ctrl+R / Ctrl+; / Ctrl+' / Ctrl+U toggles.
- **Raster tracer**: open/drop/paste PNG/JPEG/GIF/BMP/WebP → dialog with input and output panes.
  Pipeline: median despeckle → blur → unsharp sharpen → auto levels → soft fields (grey levels,
  stacked grey bands, or colour-distance fields from seeded k-means) → optional adaptive threshold
  that divides out an estimated paper brightness → open/close bump trimming → speck/pinhole removal
  → marching squares on the soft field → corner-preserving smoothing → corner reconstruction →
  dense cubic fit → line/collinear/stub clean-up. Auto recommend picks mode and every control from
  colourfulness, tone counts, Otsu separability, dust and lighting variance, and explains itself.
- **Panel layout system**: every panel section docks, floats (drag title off the dock, resize),
  minimises, reorders (drag or menu), or parks as a chip in the status-bar tray; Document and
  Snapping start parked. Right-click on the drawing lists relevant panels (recent first) plus
  contextual actions; right-click a title for layout options. Layout persists in localStorage.
- **Vertex and edge right-click menus**: everything from the panels plus align/space/weld/snap
  vertices, set position, start-here, straighten/curve around, insert or cut under the pointer,
  edge kind and arc presets, delete edge, level/plumb, set length/angle, next/previous edge.
  Delete key now follows the tool.
- Fixes found on the way: `loopToNodes` dropped loops with exactly one detected corner (silently
  lost ring holes), sharpening halos fooled the paper estimate, `bezIsStraight` now samples the
  curve rather than the control points, `viewBtns` declaration order.
- **Explanatory comments** at the user's request: a module map at the top of the script (sections
  24b, 25b, 28, 29, 30 and the two conventions they share), and a "how it works" block at the head
  of each of those sections — the align flow, the distribute maths, the morph steps, the dry-run
  preview mechanism, the three coordinate layers, the snap priority, the full tracer pipeline
  stage by stage, the auto-recommend decision order, the layout state model and header gestures.

## Decisions

- **World coordinates never change.** Units and the ruler origin are a presentation layer
  (`toDoc`/`fromDoc`); page stays at (0,0)–(w,h) in px. Keeps every existing geometry routine and
  export untouched.
- **Groups are units.** Align/distribute/morph treat a group as one block; guide placement pivots on
  the mean of each shape's untransformed box centre so repeating an action is a no-op (a rotated
  group's world bbox centre drifts, which caused a visible creep on the second press).
- **Previews run the real code.** Rather than a parallel "plan" API, `previewAction` mutes
  `pushUndo`/`save`/`status` via a `dryRun` flag, snapshots matrices/array/selection, runs the
  action, clones changed shapes as ghosts, restores. `dropUndo()` replaces bare `app.undo.pop()`
  in align code for that reason.
- **Tracer works on soft fields, never hard masks.** Anti-aliasing carries sub-pixel edge position;
  thresholding first was the root cause of the poor early results. Colour layers use centroid
  distance fields (a blend pixel sits at 0.5) and are stacked so there are no seams.
- **Adaptive threshold = divide by estimated paper**, not local mean. Local-mean thresholding
  hollowed out solid regions larger than its window. Paper estimate: 75th-percentile blocks (so
  dust and halos can't pose as paper), max filter over a third of the picture, computed on the
  pre-sharpen luminance.
- **Corner span ≈ 6 source px.** A span smaller than the blur rounding never sees a corner; that
  single parameter was the difference between a bowed blob and an exact square.
- **Fit from dense points.** DP-simplifying before the cubic fit let a cubic bow between sparse
  points while still "passing" at them. Now only exactly-collinear points are dropped (0.12 px).
- **Right-click opens panels in place only when the dock is hidden**; with the dock visible it
  flashes the docked section instead of tearing it off (less disruptive).
- Text must be exploded before morphing; morph pairs holes by index and drops extras.

## Open threads

- The morph is static (not live). Editing an endpoint does not re-blend; break apart is the only
  edit path. A live blend would need a stored `{a, b, steps}` record and a rebuild hook.
- Tracer corner rebuild treats roundings under ~3 source px as sharp corners; the Corners slider is
  the only escape. A deliberate tiny-radius rounded rectangle will come out square-cornered.
- Colour tracing on photographs is still posterised (176 shapes / 2k vertices for a 300×200
  gradient). Fine for logos; not a photo vectoriser. Performance ~2 s at 600×400 with 8 colours.
- `load()` still has no schema version (carried from earlier sessions). Old autosaves get defaults
  via `applyDocMeta`, but shape-level migrations still don't exist.
- Panel layout persistence was verified by code path only — the preview pane blocks localStorage.
- `resizeSel` anchors on the top-left even in Y-up documents (cosmetic).
- The union-shape triangle in colour stacking picks up a 25° bend as a curve (below the 50° corner
  default) — expected, but worth remembering when a logo has shallow corners.
- Session scratch files (patch*.py, *_js.txt fragments) live only in the scratchpad; nothing to
  clean in the repo.
