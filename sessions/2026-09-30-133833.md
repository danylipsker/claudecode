## What changed
- **Print-in-place base** (549b633; fibonacci_gear.py, server, card, tests, docs 29.5).
  - A plate with two axles fused to it; each axle carries a 45° double-cone ridge at
    mid-face.
  - Each gear's bore is the axle profile grown by the print clearance, so the gears are
    captive and print without supports, a clearance above the plate.
  - Choosing it raises backlash and dedendum to the clearance
    (`b = 2(c+0.01)/cos a`, `hf* = ha* + (c+0.02)/m`) and sets the print pose.
  - `print_gap` checks the pose. The plate is the gears' convex hull plus a margin.
  - Output: STEP with three bodies, which SolidWorks 2026 imports.
- **Smooth return** (af26a0a; docs 29.6).
  - A second log spiral `r = b e^(-kappa u)` replaces the step. Growth rolls on growth
    and return on return, so the gears stay identical and the speed ratio no longer
    jumps.
  - Sizes come in closed form, with both arcs half-integer pitches: a whole tooth on
    every peak and a whole gap in every valley.
  - Half the lobe is the "golden heart" (φ⁻²..φ²), the default when the option is
    chosen.
  - The corners are relieved by a shared swept-relief routine (`_swept_relief`).
  - The card gets the step/smooth toggle and the return angle; smoke flag `--fibsmooth`.
- **Cutter fillet fix** in fibonacci_gear.py (af26a0a) and involute.py (6a656a7, the
  parallel session's identical commit, fast-forwarded and pushed).
  - `v_tan = v_c + rho sin a`, not minus.
  - Before, every rack-generated gear kept up to 0.08 m of extra material on its lower
    flank, where the mating tip works: +29 µm on a z84 m1 spur.
- **Roll-sweep fix** (1f8be94, by the parallel session, landed and pushed here).
  - The ±0.7-pitch sweep left the top of every involute tooth a straight line, up to
    64 µm too thick.
  - Now within 0.16 µm of the involute to the tip.

## Decisions
- **Captive by a ridge, not a cap.** A double-cone ridge in a grooved bore prints
  without supports and holds the gear. The gears sit a clearance above the plate, which
  the slicer bridges.
- **The print pose matters.** With 0.7 mm backlash the gears print 0.31-0.34 mm apart
  from 10° to 355° of the turn, but only 0.02 mm with the steps on the line of centres.
  The card therefore sets gear 1 to the middle of the growth. The server warns when the
  pose would fuse the gears.
- **Axle size.** The automatic axle is capped at Ø10 mm; the heart's large small end
  offered Ø55, which no printed axle needs.
- **Smooth return: corners instead of a curvature-matched blend.**
  - Log spirals on both branches give closed-form sizes and exact rolling. A fully
    rounded pitch curve would need a designed λ(R), and the valley risks going concave.
  - The return's tooth count is solved so its arc is a half-integer pitch count. The
    return angle Dany enters is only a target; the details show the actual angle.
  - Default is half a lobe, not 120°. At 120° the return leans 31°, so the teeth push
    at 51° there (warned). The half-lobe return leans 17°, like the growth, and raises
    no warnings.
- **Corner relief uses one window.** The mate's valley is swept through the gear's
  peak. By the pi-rotation / time-reversal symmetry of the identical pair, that also
  clears the valley event, so no second window is needed.
- **Parallel sessions: land, don't duplicate.** The fillet fix and the roll sweep were
  also being worked by "Fix the rack fillet notch and short roll sweep".
  - When Dany said "fix it yourself", I found that session's commit already existed. I
    dropped my own identical involute.py edit, aborted a conflicting cherry-pick, and
    fast-forwarded main to its commits, which it had rebased onto main.
  - Result: one version of each fix, no merge conflicts later.
- **Shared index protocol.** Every commit this session staged only this session's
  paths, and built README/PROGRESS/docs blobs as HEAD + this session's hunks
  (`git hash-object` + `git update-index`). The staged file list was checked before
  each commit.
  - One crossing happened. My index held a stale PROGRESS blob, and the library
    session had staged its files. Both sides backed out, and the library session
    committed first.
