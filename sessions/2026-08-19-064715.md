## Decisions

- **Author circuits in the XML format, never the legacy text format.** The legacy
  switch dump has no field for `keyShortcut`, so keyboard-operated switches silently
  lose their keys on round-trip. This is the single most important format constraint
  for this project.
- **One `key` per linked switch group.** The dispatcher toggles *every* switch matching
  a pressed key, and `Switch2Elm.toggle()` then assigns its own new position across its
  whole `li` group — so two linked poles sharing a key toggle each other back and the
  key goes completely inert, with no error and no visible clue. Put the key on one pole
  and let `li` gang the rest.
- **Frequency readouts come from scopes, not voltmeters.** The voltmeter's frequency and
  period modes are dead code in v4.1.4 — the field is never computed and the period line
  is commented out. Both render 0 Hz forever. Scope flag bit 3 is the working path.
- **Do not commit another session's in-flight work.** When the parallel rebuild was
  discovered mid-flight, only the single reviewed file was committed and the rest was
  left alone until that pass went quiet, rather than sweeping 15 half-finished files
  into history.
- **Verify by reading back from the simulator, never by inspecting the file alone.**
  CircuitJS skips elements it cannot parse *without reporting an error*, so a broken
  circuit loads looking fine. Comparing the file's element-tag count against
  `getElements().length` is the check that catches it.
- **Read simulator state synchronously where possible.** `importCircuit` and `toggle()`
  are both synchronous, so element counts and switch positions can be read with no
  timers at all. This matters more than it sounds — see Open threads.

## Open threads

- **The circuit-24 fix is fragile and will regress.** Whatever the parallel session
  generates from still has `key="l"` on both poles; every regeneration reintroduces the
  bug. It was clobbered four times during this session. The durable fix belongs at that
  generator, not in the output file. If circuit 24 is rebuilt again, re-check it first.
- **The README's circuit-01 row is stale.** It advertises "**T** = trigger", but circuit
  01 now has no switch at all — the fidelity pass replaced the momentary button with a
  0.7 Hz square-wave source (93% duty, 4.5 V bias) that auto-triggers the one-shot.
  Either restore a keyed button or drop the claim; that is a call for whoever set the
  scan-fidelity goal, since the page may not draw a button.
- **Browser throttling makes timer-based verification sweeps unreliable.** Chrome
  applies intensive throttling to long-hidden pages — a requested 100 ms timer measured
  at 976 ms, and the simulator's own timer is throttled identically, so the sim barely
  steps. Sweeps that looked hung were merely crawling. The fix is to avoid timers: the
  element-count and key-actuation gates now run in ~545 ms for all 28 circuits, and only
  the solver-health check needs real wall-clock time. Reloading the page resets the
  throttle clock if a longer pass is unavoidable.
- **Verification harness is not checked in.** The gate currently lives as ad-hoc
  JavaScript pasted into the browser console against a local same-origin mirror. Worth
  turning into a committed script if this set keeps changing.
- The Mims set is complete at 28 circuits; no further circuit images were supplied this
  session, so the original "send me images and I'll build them" workflow is still open.
