## Summary
Built the Curves Workshop (`CURVES-BOOK/`): every figure of Robert C. Yates, *A Handbook on Curves and
Their Properties* (1947) rebuilt from exact geometry as a step-by-step construction naming the tool of
each stroke, with 329 SVG drawings for the book's 211 figures, the 45 sections' text, Markdown docs,
and a practice board with virtual compass, straightedge, dividers, set square and pencil that snaps to
intersections and checks every stroke. Fourteen parallel Sonnet writers drew the figures and wrote the
section texts from the scanned pages; a reviewer re-verified the conics text for pages 44–55. Pushed as
52d21de and live on GitHub Pages. The full browser self-test (figure page, step playback, board
completion with "Show") was green on the first 310 figures; the run over all 329 was still in progress
at close-out (56 done, no failures).

## Decisions
- Figures are reconstructed from geometry, never traced: the scan has no text layer and the book's
  drawings are often freehand; writers drew the true curves and recorded each departure in the
  figure's `note`. Several misprints in the book (areas, signs, a dimensionally wrong equation) were
  corrected in the section files with the printed value noted.
- The scanned book and its page images are local only (copyright and size); the published artefacts are
  the SVG reconstructions and original prose. `gallery.html` works only when `scan/` is present.
- A given length (k, a) is drawn in the `given` step as a ticked segment so the dividers can carry it;
  this keeps constructions honest on the board (found while testing Fig. 9).
- No build step, no libraries: TeX→MathML and markdown come from HYPER-CORE copies in `js/lib/`.
- The 290-vs-329 panel count: writers followed the page where the manifest's panel count was off
  (e.g. Fig. 83 has five, Fig. 149 six, Figs. 180/181 eight each, Fig. 15/21/136/201 split in two).
- Backslash-bearing edits must go through Edit/Write: the Bash tool collapses `\` in command text
  (saved to memory as `bash-backslash-collapse`).
