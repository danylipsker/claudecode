## Decisions
- Tabs are per type AND per brand/source (e.g. "DGBB Maedler", "DGBB SKF (Maedler cat)") rather than merged per type, so configuration names stay unique within a tab and catalogue values are never mixed between brands.
- Every tab repeats the NSK header block exactly (B@S, ID@S, OD@S, r_min@F1, $SW-MASS, $DESCRIPTION, IDa@S, ODa@S) so a copy of the NSK part can take any tab. Type-specific dimensions follow as extra @S columns (thrust: d1@S, D1@S). Thrust tabs put the height H in B@S, tapered tabs put the overall width T in B@S (Maedler prints only d, D, T).
- Catalogue information that is not geometry (C, C0, speeds, weights, source, page, variants) sits to the right of one empty column, because SolidWorks stops reading a design table at the first empty header cell. Row 1 of that area carries the tab's caveats.
- IDa@S / ODa@S in the new tabs are formula estimates (d + 0.2(D-d), D - 0.2(D-d)) because no source prints shoulder diameters; flagged in every tab and in README. Blank cells were rejected because SolidWorks would error on an empty dimension.
- The original NSK file was left as is; the result is a new file, not an in-place edit, so nothing can be lost.
- Catalogue misprints were copied as printed and marked in a "Catalogue check" column (Timken 6026/6028 C, 6238 vs 6338 swapped, 6252M/6244M weights, 16002 oil speed; Maedler 6305-2Z-SKF C3 number) instead of being silently corrected.
- Extraction was done with pdfplumber word coordinates, not pdftotext: on the Maedler pages pdftotext shifts the load/speed/weight columns by one row.
- Recalculation went through Excel COM (pwsh script) because LibreOffice is not installed on this machine.
- Pillow blocks, flange units, freewheels and plain bushes from the Maedler catalogue were left out: not rolling bearings for a design table.
