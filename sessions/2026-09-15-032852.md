  labelled as *not* PennEngineering/PEM(R) exact parts (that catalog is thousands of proprietary,
  patent-geometry SKUs); a representative envelope only, documented as such everywhere it appears.
- **Reference-only standards documented, not modelled:** DIN 267, DIN 17660, DIN 13, DIN 7168 (general
  delivery conditions / material spec / thread profile / general tolerances - none is a discrete
  fastener shape). Flagged for Dany: "DIN 88086" unidentified, "ISO 415" assumed to mean ISO 4161,
  "PFM" catalog unidentified.
- **Add-in dialog UX overhaul (commit 5a7a976, `FASTENERS/solidworks/addin/FastenerForm.cs`):**

## Decisions
- Kept committing straight to `main` in `fasteners-catalog` rather than branching, matching how the
  rest of this project has been done all session.
- Self-clinching families use rounded, generic proportions rather than any attempt at PennEngineering's
  real dimensions, which are proprietary; every part, drawing note and README section says so plainly.
- ISO 4034/4036/8675 needed real published tables (fetched and verified, not estimated) since they are
  small variations on existing thin/regular nuts where getting the difference wrong would be misleading.
