## Summary
Built **GEAR-REDUCTIONS**: a SOLIDWORKS add-in plus a command-line tool that takes a module and a
gear ratio, lists every tooth set of three coaxial reducer families that gives it (exactly or
nearest), and builds the picked one as native parts and a mated, animatable assembly. The design
follows Dany's three sources (Printables 357952 "500 to 1 Ultra-Compact", 3D Printer Academy's
500,000:1 stacked-stage video, mechanical-engineering.com's planetary formulas) with input and
output always coaxial. All three families were built and verified on SOLIDWORKS 2026 (parts in
place, no interference beyond touching flanks, kinematic test exact); the add-in is registered and
loads. GEAR-REDUCTIONS is its own git repository inside this one (seven commits, no remote yet).

## Decisions
- Three families instead of one, because the sources describe three mechanisms: planetary stages
  (the video), the wobble ring with a pin-coupled output (Printables), the two-ring 3K (the earlier
  HIGH-RATIO-GEAR-SET work, proven). The table shows all of them so the trade-off is visible: with
  standard involutes the wobble ring needs a tooth difference >= 6 and tops out near 1:300 per
  stage; 1:500 comes from the 3K (180 mm) or three planetary stages.
- The Printables toy was measured from its STL files (sun 16, one planet 32, corrugated ring 80,
  fixed ring 100, e = 1 mm, four pips) rather than copied: its meshes are not exact (three different
  modules) and its counts roll at 1:29, so the wobble family is that mechanism made exact.
- The builder is family-agnostic: a family emits parts as extruded profiles in absolute Z plus
  mates; the builder only interprets. New layouts touch the Core only.
- SOLIDWORKS gear mates: measured on 2026 that they relate spins about the line of centres, so an
  orbiting gear gets the plain tooth ratio and a coaxial part its absolute ratio; the flip sense
  depends on face alignment, so Verify drives the input with a temporary angle mate and corrects a
  wrong mate. IDragOperator crashed the server and was dropped.
- Backlash default stays 0 (theoretical, touching flanks show as 0 mm3 "interferences").
- No GitHub remote was created for GEAR-REDUCTIONS: the permission classifier refused `gh repo
  create` and the push; Dany creates danylipsker/gear-reductions (private, https) and pushes.
