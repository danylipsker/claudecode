## Decisions

- **The source page's equations are MathJax CHTML markup, not scrapeable text** — so the
  page was used only for the curve roster; every parametric/polar form was implemented
  from standard math. History notes were written fresh, not copied (the page's prose is
  copyrighted).
- **One uniform curve model for built-ins and customs** ({aux, x, y, z} expression
  strings + params + t-domain). This is what makes Clone-to-edit possible; built-ins are
  not privileged JS closures.
- **Gaps via NaN + screen-space jump-breaking**, not clamping: expressions return NaN
  outside their domain (sqrt of negatives does it naturally) and the renderer lifts the
  pen on NaN or on segments longer than ~¾ of the view — this single mechanism handles
  lemniscate domains, conchoid/hyperbola asymptotes and folium poles with no special
  cases.
- **Two-branch curves (Cassini, Cartesian oval, Fermat, Pearls) parametrize both
  branches over a doubled t-range with ternaries on t** instead of a multi-piece curve
  model — keeps the editor a simple triple of expressions. Cartesian oval solves its
  bipolar equation as a quadratic in r₁ (closed form, no iteration).
- **The expression compiler builds its prelude per-curve with exclusion sets so
  parameters/helpers may shadow built-ins** (found when Trident of Newton's classic
  parameter `e` collided with Euler's constant). Only `t` and `P` are reserved. `^` is
  preprocessed to `**`; a paren-balance check and an exponentiation hint
  ("write -(x^2)") make the two most common input errors readable.
- **Autofit uses a percentile-trimmed bbox** (~80th ×1.6) so asymptotic curves
  (Kampyle, conchoid, spirals) fit on their meat rather than their blow-ups.
- **3D is a hand-rolled projector** (orbit camera, perspective divide, per-segment
  depth-shaded stroke) — no three.js, matching the repo's self-contained-tool
  convention. Devil's curve polar form was re-derived because the first attempt had the
  denominator sign flipped (correct: r² = (b²cos²θ − a²sin²θ)/(cos²θ − sin²θ),
  classic shape at a/b = √24/5).
- **Verification under a hidden pane**: rAF never fires, so the frame loop was pumped
  manually via javascript_tool; canvas-to-base64 hand transcription proved corruptible
  and was abandoned for `msedge --headless=new --screenshot` renders, which worked
  cleanly. Worth remembering for future pane-less UI verification.
- Bugs fixed before ship: unary-minus-before-`**` (frequency curve), the `e` collision,
  editor-lifecycle crashes around unsaved new curves, cold-start fit when the canvas has
  zero size (fitPending + ResizeObserver), 3D grid sized from camera distance instead of
  the curve.
